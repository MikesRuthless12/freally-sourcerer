Freally 0.23.0 — Stable. Portable mode, media playback, and search that tells you what it can't see

Signed auto-updater + per-OS installers. Instant cross-platform search across four lenses — filename, full-text content, audio attributes, and fuzzy name — fed by a realtime filesystem journal. The next Everything, for Windows, macOS, and Linux.

The stable release. This is the last of the three Must-Have builds, and it closes the feature gate: everything a reviewer would reach for in the first hour against Everything 1.5, Listary 6 or Agent Ransack is now in the box. Run the whole app from a USB stick without touching the host machine. Audition audio without leaving the results list. Compose a regular expression against the filenames already on screen. And when a folder cannot be read, the app says so — instead of quietly returning nothing, which is what every previous version did.

What's included

  • New in 0.23.0 — Portable mode: --portable, or a portable.flag file beside the binary, keeps the index, settings, bookmarks and logs in a Data/ folder next to the app — and registers nothing with the operating system.
  • New — Inline audio and video playback in the preview pane: transport, seek, loop, volume, a clickable waveform, and the loudness and codec badges overlaid.
  • New — Spacebar Quick Look: a large preview that stays open while the arrow keys walk the result set.
  • New — Regex builder and live tester: write a pattern against the names already on screen, with the engine's own error and a match count, before committing it to the query.
  • New — Permission health report: which folders could not be read, on which volume, for what reason — with the fix for your platform, including a macOS Full Disk Access walkthrough that detects whether it is already granted.
  • New — Bookmarks and filters sidebar: bookmarks, type filters, volumes and recent searches in one column, with drag-reorder.
  • New — Ignore punctuation and ignore whitespace, so foobar finds foo-bar, plus anchored matching with name^: and name$:.
  • New — Natural sort by default: file2 before file10, v1.9 before v1.10.
  • Live change journaling: the index follows the filesystem as it changes, via the USN journal on Windows, FSEvents on macOS, and inotify on Linux.
  • Index Health panel: per-volume monitoring state, events applied, queue depth and lag, with advisories that carry a one-click fix.
  • Bulk rename across a result set: literal or regex find/replace with capture groups, {n} counters, and case transforms, with a live preview and all-or-nothing collision blocking.
  • Undo/redo for file operations, so a rename that went wrong is one keystroke back.
  • Offline removable-volume catalogs: an unplugged drive stays searchable, and every row says which device it lives on.
  • Machine-readable CLI: --json, --ndjson, --csv, --fields, -0 for xargs -0, and meaningful exit codes.
  • Shell completions for bash, zsh, fish and PowerShell, including modifier keywords and your saved-search names.
  • Typo-tolerant “did you mean”: a no-hit filename search offers the closest real match as a one-click correction.
  • CJK phonetic matching: wenjian or wj finds 文件, romaji finds kana, lead jamo finds Hangul.
  • Duplicate finder — dupe:, name-dupe: and size-dupe: cluster matching files under a group header, straight from the index.
  • Empty-space finder — empty:, child-count: and descendant-count:, including the roots of nested empty folder chains.
  • Everything file lists — import and export .efu byte-compatibly, plus CSV, TXT, M3U playlists, and NDJSON.
  • Search within results — Ctrl+Shift+F narrows what's on screen as a stack of removable chips.
  • Hit-in-context viewer — every match in a document, highlighted, with F3 / Shift+F3 navigation.
  • Result verbs — Open with…, copy contents, copy as file, copy path list, open terminal here, and your own custom commands.
  • Filename lens — instant filename, glob, and regex search on multi-million-file disks with sub-16 ms P99 results.
  • Content lens — full-text search across PDFs, Office documents, source code in 32 languages, archives (peeked without extracting), and structured files like JSON, CSV, and YAML.
  • Audio lens — search audio files by duration, LUFS loudness, codec, sample rate, silence ratio, and dynamic range using query modifiers like lufs:<-14 and codec:flac.
  • Similarity lens — find near-duplicate filenames via bigram MinHash. "I named it something like…" actually works.
  • Full Settings dialog modeled on voidtools' Everything Options — 26 panels, left-tree navigation, per-OS volume detection.
  • 18 languages, live-switching, with automatic right-to-left layout for Arabic.
  • Zero telemetry, no accounts, no cloud. Your index never leaves your machine.
0.22.0 Aug 2, 2026

Live index updates, bulk rename, and a scriptable CLI

Build 2 of the Must-Have stable gate. The index started updating as files change rather than only when a scan runs, and an Index Health panel reported what was actually being watched, what fell behind, and what to do about it. Rename a whole result set with find/replace, regex captures and counters — previewed before anything touches disk, blocked outright if two files would collide, and undoable with Ctrl+Z. The CLI learned JSON, NDJSON and CSV for scripting, and unplugged drives kept their own searchable catalogue.

0.21.0 Jul 31, 2026

Duplicates, empty folders, and every result verb

Build 1 of the Must-Have stable gate. Find duplicates with dupe:, empty files and folders with empty:, and read Everything's .efu file lists both ways. Every result row gained a right-click menu: Open with, view matches in context, copy contents or the file itself, open a terminal there, or run a command you defined.

A Tauri 2 + Svelte 5 search experience: live tokenization, lens-grouped results, drag-resize columns, bookmarks, quick filters, preview pane, global hotkey, light/dark/system themes, and a full Everything-equivalent menu bar.

Phase 9 2026

Audio lens

EBU R128 loudness, true peak, silence ratio, and dynamic-range analysis with lufs:, codec:, length:, rate:, silence:, and dr: query modifiers.

Phase 8 2026

Content lens

Full-text extractors for plain text, Markdown, PDF, Office (docx/xlsx/pptx), source code in 32 languages, archives (peek without extracting), and JSON/CSV/YAML structured data.

Phases 1–4 2026

The index core

Per-OS filesystem journals (NTFS USN on Windows, FSEvents on macOS, inotify + fanotify on Linux) feeding a Tantivy + trigram name index over a SQLite WAL store.
